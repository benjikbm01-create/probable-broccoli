# Void Outlaws

A multiplayer Fabric mod for **Minecraft Java Edition 1.21.1**: you and your friends share one crew,
one ship and one hideout. Everything you need to learn is taught in-game by the tutorial.

> **No spoilers in this file.** `SPOILERS.md` is for developers only and describes all the content. Players: don't open it!

---

## What to install

| Thing | Version |
|---|---|
| Minecraft Java Edition | **1.21.1** |
| Fabric Loader | **0.20.1** (any 0.16 or newer works) |
| Fabric API | **0.116.18+1.21.1** |
| Void Outlaws | `release/void-outlaws-1.0.0.jar` (or build it yourself, see below) |
| Java (only for servers / building) | **21** |

**Everyone needs the mod.** The server (or the LAN host) *and* every player must have both
**Fabric API** and **Void Outlaws** in their `mods` folder.

Downloads:
- Fabric installer (for the Loader): https://fabricmc.net/use/installer/
- Fabric API: https://modrinth.com/mod/fabric-api (pick the `1.21.1` version)

## Install on your own computer (each player)

1. Run the Fabric installer, choose **Client**, Minecraft **1.21.1**, and the latest loader. Click Install.
2. Open your `.minecraft/mods` folder (create it if it doesn't exist):
   - Windows: press `Win + R`, type `%appdata%\.minecraft`, open `mods`
   - macOS: `~/Library/Application Support/minecraft/mods`
   - Linux: `~/.minecraft/mods`
3. Put **`fabric-api-0.116.18+1.21.1.jar`** and **`void-outlaws-1.0.0.jar`** in there.
4. In the Minecraft Launcher, pick the **fabric-loader-1.21.1** profile and press Play.

## Play together on a LAN world (easiest)

1. The host creates a **new** world (Survival, difficulty **Easy** or **Normal** so there are enemies).
2. In the world, press `Esc` → **Open to LAN** → Start LAN World.
3. Friends on the same network open **Multiplayer**; the world shows up at the bottom. Join it.

(Friends not on the same Wi-Fi can't use LAN; use a server instead.)

## Play together on a server

1. Download the Fabric **server** launcher for 1.21.1 from https://fabricmc.net/use/server/ and put it in an empty folder.
2. Run it once (for example `java -Xmx3G -jar fabric-server-launch.jar nogui`). It creates files and stops.
3. Open `eula.txt` and change `eula=false` to `eula=true`.
4. Put **`fabric-api-0.116.18+1.21.1.jar`** and **`void-outlaws-1.0.0.jar`** in the server's `mods` folder.
5. Start the server again. Friends join with your server's address under **Multiplayer → Add Server**.

Tips:
- Use a **fresh world** for the best experience.
- Set `difficulty=easy` (or `normal`) in `server.properties`; on Peaceful, enemies don't show up.
- The mod turns on the `keepInventory` game rule once when the world first starts (casual-friendly).
  You can turn it off with `/gamerule keepInventory false` if you like.

## How to start the tutorial

You don't have to do anything: **the first time a player joins, they are moved onto the crew's ship and
the tutorial starts automatically.** Follow the gold text on screen and in chat.

- `/tutorial` shows your current tutorial step again.
- `/tutorial restart` replays the tutorial from the start.
- `/tutorial skip` skips it. `/tutorial hints off` turns off the reminder pop-ups.
- `/guide` prints a quick reminder of the controls and gives you a new **Outlaw's Handbook**
  (right-click the book to read it).

Friends can join or leave at any time. A friend who joins later gets their own tutorial.

## Commands

| Command | What it does |
|---|---|
| `/tutorial` | Show your current tutorial step (`restart`, `skip`, `hints on/off`) |
| `/guide` | Quick controls reminder + a fresh handbook |
| `/crew` | Crew status: ship location, Heat, money, job, who's at which station |
| `/pay <player> <amount>` | Give some of your credits to a crewmate |
| `/unstuck` | Beam back aboard the ship if you get stuck somewhere |

Server operators also have `/outlaws ...` (for fixing problems): `heat`, `hull`, `pot`, `credits`,
`story`, `canceljob`, and `rebuild` (rebuilds all the mod's buildings if something got broken).

## Build it yourself

You need **Java 21** (JDK). From the `void-outlaws` folder:

```bash
./gradlew build
```

On Windows use `gradlew.bat build`. The jar appears in `build/libs/void-outlaws-1.0.0.jar`.
The first build downloads Minecraft and Fabric files, so it takes a few minutes.

Version notes: Minecraft 1.21.1, Yarn `1.21.1+build.3`, Fabric Loader `0.20.1`, Fabric API
`0.116.18+1.21.1`, Fabric Loom `1.11.8` with Gradle `8.14.3` (the Gradle wrapper is included).

Textures are generated by `tools/gen_textures.py` (Python 3 + Pillow); the generated PNGs are already included.
