# ⚠ SPOILERS — story files

This folder holds the complete private narrative for *The Forgotten Island*: the
story bible, character arcs, endings and all dialogue sources.

**If you want to experience the story yourself, do not open anything in this
folder** (or `mod/src/main/resources/data/forgotten_island/fi/`, which contains
the generated dialogue). Player-facing, spoiler-free material lives in `docs/`.

Developers can test mechanics without reading story text by enabling developer
mode in game (`/fi dev on`), which hides all dialogue and objective text.
