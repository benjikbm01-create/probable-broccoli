# Attribution and licences

## Original work in this project
Everything below was created specifically for *The Forgotten Island*:
- **Story, characters, dialogue, books and quests.**
- **All character skins** (seven residents plus one adversary). They're painted procedurally by `tools/skins/make_skins.py` from hand-designed face and hair grids. No third-party skins were used, so there are no redistribution questions.
- **The island and every structure.** Each is generated by the code in `mod/src/main/java/dev/forgottenisland/build/`. No third-party schematics or building assets were used.
- **Block and item textures** for the custom puzzle blocks, the journal and the Ember (`tools/` scripts), and the mod icon.

## Reference images
The brief mentioned supplied reference images for the building standard.
